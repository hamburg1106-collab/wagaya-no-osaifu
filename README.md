# わが家のお財布

レシートを撮ると記録される、夫婦2人用の家計簿。Vite + React + TypeScript の PWA。

- 公開先: https://hamburg1106-collab.github.io/wagaya-no-osaifu/
- 目的は**記録と見える化**。予算管理・残額アラート・貯金の逆算はやらない
- 設計の経緯は `draft/わが家のお財布-仕様.md`

## 使う前の準備

1. **Firestoreのルールを貼る**
   Firebaseコンソール → `ouchi-no-kondate` → Firestore → ルール。
   `firestore.rules` の `ここに合言葉` を `合言葉.txt` の文字列に置き換えて貼る。
   **このプロジェクトは他のアプリと共用しているので、既存の行を消さないこと。**
2. **Gemini APIキーを取る**
   Google AI Studio で1つ発行し、アプリの設定画面に貼る。夫婦で同じキーでよい。
3. **固定費を登録する**
   設定 → 固定費。土地ローン・ネット代・おむつサブスクは「毎月同じ」、
   電気・水道は「毎月変わる」。
4. **相手の端末に渡す**
   設定 →「リンクを送る」。合言葉付きのURLが飛ぶので手打ち不要。
   開いたらホーム画面に追加してもらう。

## しくみ

- レシート写真は 1600px に縮めてから Gemini に送り、`responseSchema` でJSONを強制する
- **写真は保存しない。** 解析が終わったら捨てる（Firebase Storage は使わない）
- 記録は `kakeibo/{合言葉}/receipts`。合言葉を知らない人はパスを当てられない
- 固定費は起動時に自動計上。`kakeibo/{合言葉}/fixedLog/{YYYY-MM}` を
  トランザクションで確認するので、夫婦が同時に開いても二重にならない

## 気をつけること

- **無料枠なので、送ったレシート画像はGoogleの製品改善に使われる。**
  止めたいときはAPIキーのプロジェクトで課金を有効にする（コードの変更は不要）
- **月の途中で固定費を足しても、その月が計上済みなら反映されない。**
  その月ぶんは手入力で足すか、翌月から効くものとして扱う
- **アプリを一度も開かなかった月は固定費が計上されない。**
  PWAはバックグラウンドで動けないため。次に開いたときにまとめて計上される
- モデル名は `src/config.ts` の `GEMINI_MODEL`。404になったらここを直す
- 更新は `main` にpushすると GitHub Actions が自動でビルドして公開する
