# わが家のお財布

レシートを撮ると記録され、**この先いくら要るかが見える**夫婦2人用の家計簿。
Vite + React + TypeScript の PWA。

- 公開先: https://hamburg1106-collab.github.io/wagaya-no-osaifu/
- 設計の経緯は `draft/わが家のお財布-仕様.md`
- 個人の資産管理は別アプリ（[これ買っていい](https://hamburg1106-collab.github.io/kore-katte-ii/)）

## このアプリが答えること

1. **今月いくら使ったか** — レシートを撮ると、カテゴリ別の内訳に分けて記録する
2. **この先足りるか** — 貯蓄残高・収入・ライフイベントから、残高が尽きる月を出す

2つ目が本体です。家計は車検・固定資産税・保育料・出産費用・大学費用といった大物を
全部背負っているのに、月々の記録からはそれが見えません。そこを見えるようにするのが目的です。

## 使う前の準備

1. **2人ともアプリを開いてGoogleログインする**（この時点では「権限がありません」と出る）
2. **Firebaseコンソール → Authentication → ユーザー** で2人のuidをコピーする
3. **`firestore.rules` の `UID_TOSHI` / `UID_TSUMA` を本物に置き換えて、コンソールのルールに貼る**
   このプロジェクトは他のアプリと共用しているので、既存の行を消さないこと
4. **Gemini APIキーを取る** — Google AI Studio で1つ発行し、設定画面に貼る（夫婦で同じキーでよい）
5. **設定で「貯蓄残高」「収入」「固定費」を入れる**
6. **見通しタブで、この先の大きな出費を置く**

## しくみ

- レシート写真は 1600px に縮めてから Gemini に送り、`responseSchema` でJSONを強制する
- **写真は保存しない。** 解析が終わったら捨てる（Firebase Storage は使わない）
- データは `kakeibo/wagaya/...`。読めるのはルールに書いた2つのuidだけ
- 固定費は起動時に自動計上。`fixedLog/{YYYY-MM}` をトランザクションで確認するので、
  夫婦が同時に開いても二重にならない
- 見通しの支出は**実績の平均**を使う（今月は含めない）。記録が無いうちだけ手置きの想定額を使う
- 利回りも物価上昇も入れない。前提を増やすと、外れたときに理由が分からなくなる

## 気をつけること

- **無料枠なので、送ったレシート画像はGoogleの製品改善に使われる。**
  止めたいときはAPIキーのプロジェクトで課金を有効にする（コードの変更は不要）
- **月の途中で固定費を足しても、その月が計上済みなら反映されない。**
  その月ぶんは手入力で足すか、翌月から効くものとして扱う
- **アプリを一度も開かなかった月は固定費が計上されない。** PWAはバックグラウンドで動けないため
- **貯蓄残高は手で更新する。** 口座連携はしない。月に一度直せば十分
- モデル名は `src/config.ts` の `GEMINI_MODEL`。404になったらここを直す
- 更新は `main` にpushすると GitHub Actions が自動でビルドして公開する
